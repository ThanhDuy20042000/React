# React

Mẫu triển khai logic cốt lõi cho **Plugin Vòng Quay May Mắn** dùng tại hội chợ.

## Thành phần chính

- `plugin/luckyWheelPlugin.js`: Engine xử lý nghiệp vụ quay thưởng.
- `plugin/luckyWheelPlugin.test.js`: Bộ test tự động cho các case quan trọng.
- `docs/PLUGIN_SPEC_VI.md`: Đặc tả nghiệp vụ + kỹ thuật bằng tiếng Việt.

## Chạy test

```bash
node --test plugin/luckyWheelPlugin.test.js
```
